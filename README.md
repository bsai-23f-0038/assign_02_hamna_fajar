# Assignment 02 - PDF Text Processing & Analysis

This repository contains the code for Assignment 2, which focuses on text extraction from PDF files, text preprocessing using NLTK, and feature extraction using TF-IDF.

## Prerequisites & Installation

Before running the code, you need to install the required Python libraries. You can install them by running the following command in your terminal or inside the notebook cell:


pip install PyPDF2 plotly pandas scikit-learn nltk
